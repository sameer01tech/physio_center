# Physiotherapy Center Patient Management Portal

A web-based patient management system developed for physiotherapy centers to simplify and manage daily operations. The portal helps manage patient records, track attendance, monitor payments, and organize patient information in one centralized system.

Built using **Python, Django, and MySQL**, this application aims to reduce manual paperwork and improve the efficiency of physiotherapy center management.

## 🚀 Features

- **Patient Management** — Add, view, update, and manage patient information.
- **Attendance Management** — Track patient attendance and maintain attendance records for physiotherapy sessions.
- **Payment Management** — Record patient payments and track payment history.
- **Patient Records** — Maintain organized records of registered patients.
- **Database Management** — Store and manage application data using MySQL.
- **Web-Based Portal** — Access the system through a web browser.
